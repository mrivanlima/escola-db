## Implementation Checklist per Entity

For each entity, ensure:

- [ ] Domain entity created in `Escola.Domain`
- [ ] EF Core configuration in `Escola.Infrastructure/Persistence/Configurations`
- [ ] DTOs created in `Escola.Application/DTOs`
- [ ] Validators created using FluentValidation in `Escola.Application/Validators`
- [ ] Command/Query handlers in `Escola.Application` (CQRS pattern)
- [ ] Controller in `Escola.Api/Controllers`
- [ ] All responses use `ApiResponse<T>` wrapper
- [ ] RLS policies configured in database
- [ ] Soft delete implemented (deleted_at)
- [ ] Audit fields mapped (created_at, created_by, updated_at, updated_by)
- [ ] Only UUID exposed in DTOs (never internal IDs)
- [ ] Tenant isolation enforced via `ICurrentUserService`
